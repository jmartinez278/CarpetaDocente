## 1. Marco de referencia

Los atributos de calidad se clasifican según el modelo de calidad del producto de la norma ISO/IEC 25010:2023 [ISO-25010-2023]. Cada uno se expresa como un escenario de calidad con seis partes: fuente, estímulo, entorno, artefacto, respuesta y medida. Todas las medidas tienen un umbral cuantitativo.

Los umbrales están pensados para una institución educativa pública de primaria. Se asume un solo servidor de bajo costo, sin infraestructura de nube de gran escala, dentro del presupuesto del proyecto (RES-06 del documento 04).

### 1.1. Condiciones de operación asumidas

| Condición | Valor | Origen |
|---|---|---|
| Usuarios concurrentes máximos | 30 | 24 docentes de la población declarada en la tesis, más la dirección y el administrador, con margen |
| Franja de uso con disponibilidad garantizada | Todos los días, de 6:00 a 23:00, hora de Lima | Los docentes planifican también fuera del horario escolar |
| Conexión de referencia | Datos móviles 4G, simulados con el perfil **Slow 4G** de la limitación de red de Chrome DevTools (en la interfaz en español el nombre puede aparecer traducido). En cada medición se anota la versión de Chrome | Información de Nayely Cuicapuza Remigio, integrante del equipo y encargada del acercamiento con la I.E. (comunicación directa, 19/10/2026): solo el aula de cómputo y la dirección tienen wifi, las aulas no tienen computadora y hay cobertura 4G/5G de los operadores |
| Archivos de sesión | Word o PDF, hasta 10 MB por archivo | Decisión del equipo |

## 2. Escenarios de calidad

| ID | Categoría ISO/IEC 25010:2023 | Escenario de calidad (Fuente → Estímulo → Entorno → Artefacto → Respuesta → Medida) |
|---|---|---|
| RNF-001 | Eficiencia de desempeño – comportamiento temporal | **Fuente:** docente. **Estímulo:** guarda la asistencia o las notas de su sección. **Entorno:** operación normal con 30 usuarios concurrentes. **Artefacto:** módulos de asistencia y de notas. **Respuesta:** guarda y confirma la operación. **Medida:** tiempo de respuesta del servidor ≤ 2 s en el percentil 95 (P95). |
| RNF-002 | Eficiencia de desempeño – utilización de recursos | **Fuente:** docente. **Estímulo:** abre el sistema por primera vez en el día. **Entorno:** celular con el perfil Slow 4G simulado de Chrome DevTools (sección 1.1). **Artefacto:** interfaz web. **Respuesta:** carga la pantalla de inicio de sesión. **Medida:** ≤ 2 MB transferidos y pantalla usable en ≤ 5 s. |
| RNF-003 | Eficiencia de desempeño – comportamiento temporal | **Fuente:** docente o dirección. **Estímulo:** exporta las notas o la asistencia de una sección. **Entorno:** operación normal. **Artefacto:** funciones de exportación (RF-024, RF-034, RF-041). **Respuesta:** genera el archivo. **Medida:** archivo disponible en ≤ 5 s para una sección. |
| RNF-004 | Eficiencia de desempeño – capacidad | **Fuente:** docente. **Estímulo:** sube el archivo de una sesión. **Entorno:** operación normal. **Artefacto:** repositorio de sesiones (RF-010). **Respuesta:** acepta o rechaza el archivo. **Medida:** se aceptan archivos Word o PDF de hasta 10 MB; el 100 % de los archivos de otro tipo o de mayor tamaño se rechaza con un mensaje que indica el motivo. |
| RNF-005 | Compatibilidad – coexistencia | **Fuente:** docente. **Estímulo:** usa el sistema desde su celular o su computadora. **Entorno:** Chrome en Android, Safari en iPhone, y Chrome, Edge o Firefox en computadora, en sus 2 últimas versiones estables. **Artefacto:** interfaz web. **Respuesta:** muestra y ejecuta todas las funciones. **Medida:** el 100 % de los RF de prioridad Alta funciona en esos navegadores y en pantallas desde 360 px de ancho, sin desplazamiento horizontal de la página ni de ningún componente. Las tablas de dos dimensiones (por ejemplo, estudiantes × días) se transforman: se elige una dimensión y la otra se muestra como lista. |
| RNF-006 | Compatibilidad – interoperabilidad | **Fuente:** dirección o docente. **Estímulo:** abre un archivo exportado por el sistema. **Entorno:** Microsoft Excel o LibreOffice Calc. **Artefacto:** archivos de exportación. **Respuesta:** el archivo abre con los datos completos. **Medida:** 0 errores de apertura y 0 diferencias de datos frente a lo registrado en el sistema, en 10 archivos de prueba. |
| RNF-007 | Capacidad de interacción – aprendibilidad | **Fuente:** docente del piloto sin experiencia previa con el sistema. **Estímulo:** realiza sus primeras tareas después de una capacitación de ≤ 30 min. **Entorno:** prueba piloto. **Artefacto:** sistema completo. **Respuesta:** completa las tareas sin ayuda. **Medida:** ≥ 80 % de los docentes completa sin ayuda tres tareas: subir una sesión, registrar la asistencia de una jornada y registrar una nota. |
| RNF-008 | Capacidad de interacción – inclusividad | **Fuente:** docente con dificultades visuales leves. **Estímulo:** lee y opera una pantalla. **Entorno:** uso normal. **Artefacto:** interfaz web. **Respuesta:** el contenido es legible y operable. **Medida:** contraste de texto ≥ 4,5:1 (criterio de nivel AA de WCAG 2.1 [W3C-2018]) y 0 errores críticos en la revisión automática de accesibilidad de cada pantalla. |
| RNF-009 | Fiabilidad – disponibilidad | **Fuente:** cualquier usuario. **Estímulo:** intenta usar el sistema. **Entorno:** franja de 6:00 a 23:00, todos los días. **Artefacto:** servidor y aplicación. **Respuesta:** el sistema atiende la solicitud. **Medida:** disponibilidad ≥ 99 % mensual dentro de la franja; el mantenimiento programado se hace fuera de ella. |
| RNF-010 | Fiabilidad – recuperabilidad | **Fuente:** falla del servidor o daño de los datos. **Estímulo:** se pierde el acceso a la base de datos o a los archivos. **Entorno:** producción. **Artefacto:** base de datos y repositorio de archivos. **Respuesta:** se restaura desde la última copia de respaldo. **Medida:** copia de respaldo diaria, pérdida máxima de datos de 24 h (RPO), restauración en ≤ 8 h (RTO) y copias conservadas durante 30 días. |
| RNF-011 | Fiabilidad – tolerancia a fallos | **Fuente:** red del docente. **Estímulo:** se corta la conexión mientras se guardan notas o se marca la asistencia. **Entorno:** datos móviles inestables. **Artefacto:** módulos de notas y asistencia. **Respuesta:** en notas, no guarda nada parcial y conserva los datos en pantalla para reintentar. En asistencia, cada estado se guarda solo, estudiante por estudiante; si un guardado falla, la fila lo indica y reintenta; una jornada con estudiantes sin estado queda visible como incompleta. **Medida:** en 10 pruebas de corte de red durante el guardado: 0 registros parciales de notas, 0 toques de asistencia perdidos o duplicados, y el 100 % de las filas con guardado fallido lo indica. |
| RNF-012 | Seguridad – autenticidad | **Fuente:** persona no autorizada. **Estímulo:** intenta adivinar la contraseña de una cuenta. **Entorno:** producción. **Artefacto:** inicio de sesión (RF-001). **Respuesta:** bloquea la cuenta temporalmente. **Medida:** bloqueo de 15 min tras 5 intentos fallidos consecutivos; contraseñas de 8 caracteres como mínimo, guardadas solo como hash, nunca en texto legible. |
| RNF-013 | Seguridad – confidencialidad | **Fuente:** docente autenticado. **Estímulo:** intenta ver o modificar datos de una sección que no tiene asignada. **Entorno:** producción. **Artefacto:** control de acceso por rol (RF-004). **Respuesta:** niega el acceso y lo registra. **Medida:** el 100 % de los casos de prueba de la matriz de permisos del documento 08 se resuelve según esa matriz. |
| RNF-014 | Seguridad – confidencialidad e integridad | **Fuente:** atacante externo. **Estímulo:** intercepta el tráfico o intenta explotar una vulnerabilidad conocida. **Entorno:** producción. **Artefacto:** comunicación y aplicación web. **Respuesta:** el tráfico no se puede leer y el ataque no se ejecuta. **Medida:** 100 % del tráfico cifrado mediante HTTPS y 0 vulnerabilidades críticas o altas de la lista OWASP Top 10 [OWASP] en el análisis previo al piloto. |
| RNF-015 | Seguridad – autenticidad (sesión) | **Fuente:** docente. **Estímulo:** deja el sistema abierto sin usarlo. **Entorno:** celular o computadora compartida. **Artefacto:** gestión de la sesión (RF-002). **Respuesta:** cierra la sesión automáticamente. **Medida:** cierre tras 60 min de inactividad. |
| RNF-016 | Seguridad – responsabilidad | **Fuente:** cualquier usuario. **Estímulo:** crea, modifica o elimina un registro, o intenta una operación sin permiso. **Entorno:** producción. **Artefacto:** registro de actividad (RF-008). **Respuesta:** guarda quién, qué y cuándo. **Medida:** el 100 % de esas operaciones queda registrado y se conserva al menos durante el año escolar en curso. |
| RNF-017 | Adecuación funcional – corrección funcional | **Fuente:** dirección o docente. **Estímulo:** consulta totales de asistencia o consolidados de notas. **Entorno:** operación normal. **Artefacto:** consultas y consolidados (RF-033, RF-040). **Respuesta:** muestra los totales. **Medida:** 0 diferencias entre los totales mostrados y el recuento de los registros, en un conjunto de prueba de 3 secciones con un periodo completo de datos ficticios. |
| RNF-018 | Mantenibilidad – capacidad de prueba | **Fuente:** equipo de desarrollo. **Estímulo:** integra un cambio al código. **Entorno:** desarrollo. **Artefacto:** código fuente. **Respuesta:** se ejecutan las pruebas y el análisis estático. **Medida:** cobertura de pruebas unitarias ≥ 80 % del código del cambio y 0 vulnerabilidades críticas o altas en el análisis estático, según los criterios 1 y 2 de la Definición de Hecho (DoD) del documento de planificación. |
| RNF-019 | Flexibilidad – instalabilidad | **Fuente:** administrador. **Estímulo:** necesita instalar el sistema en un servidor nuevo. **Entorno:** cambio de proveedor de alojamiento o traspaso a la I.E. **Artefacto:** sistema completo y manual técnico. **Respuesta:** el sistema queda operativo. **Medida:** despliegue completo en ≤ 2 h siguiendo el manual técnico, sin pasos no documentados. |

La característica de **protección** (*safety*) de la versión 2023 no aplica: el sistema no controla equipos ni procesos que puedan causar daño físico.
